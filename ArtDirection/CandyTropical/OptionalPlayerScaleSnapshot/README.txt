Optional half-size player snapshot for the existing CastlePrototype project. These files preserve the current survivor implementation and prefab, with their original GUIDs. Their original locations are Assets/CastlePrototype/Scripts/CastleSurvivor.cs and Assets/CastlePrototype/Prefabs/CastleSurvivor.prefab. The art Unity package deliberately excludes this gameplay change, so importing art later does not resize players or alter gameplay physics. Use this snapshot only if explicitly restoring the half-size player into the matching prototype; compare current code first. Player Scale 0.5 gives 0.85m body height, 0.12m radius, and 0.8m eye height while preserving movement speed and jump height.
