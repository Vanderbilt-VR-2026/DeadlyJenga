   a remote avatar rig already destroyed by scene unloading. RemovePeer now guards it.
   Found in ProcessSweep1; rebuilt player and reran ProcessSweep2 cleanly.

   sending selections by index. Fusion and nearby discovery now use the protocol plus
   a deterministic fingerprint of ordered map/mode IDs and mode availability. Visual
   titles do not invalidate compatibility. Incompatible wire/scene-build ordering or
   physics-content edits still need a manual protocol increment. Rebuild both APKs.
3. Empty drafting maps no longer advertise the absent castle as their TopHeight.
   All six now verify the actual ground/spawn height during Play Mode.
4. Climbing resets VR smoothing velocity at a new grip and mantle transition so a
   previous climb cannot carry its smoothing state into another climb.
5. In-game control hints now match left-controller flight trigger/grip/X turning and
   spare-hand gesture flight. Removed the nonexistent survivor left-pinch locomotion
   hint; survivor jump hints follow Standing/Seated and pinch/fist selection.
6. Repaired validation harness issues: synthetic bitfield input events, headless editor
   focus settings, and screenshots on null graphics devices. Final hand run used real
   desktop graphics and generated four fixture images. These were test bugs, not
   evidence of physical headset input failure.
