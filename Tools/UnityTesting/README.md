# Unity testing tools

- `Run-UnityTests.ps1` — run Unity tests in batch mode, write `results.json`.
- `Publish-TestSummary.ps1` — turn results into a report comment / job summary.
- `Invoke-LocalDiagnostics.ps1` — optional read-only Antigravity diagnosis of a failure.
- `Install-Runner.ps1` — register this PC as the self-hosted runner.

Full guide: [Docs/automated-testing.md](../../Docs/automated-testing.md).
