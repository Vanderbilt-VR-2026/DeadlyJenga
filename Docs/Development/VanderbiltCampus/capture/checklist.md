# Capture checklist (print me)

Date: ________  Device(s): ________  Area / buildings: ________________

## Before leaving

- [ ] Weather: overcast or even light, dry surfaces
- [ ] Phone charged; battery pack charged; cable packed
- [ ] At least 20 GB free on the phone (360 camera card empty and in)
- [ ] Settings: RAW or highest quality, 1x lens, HDR / night mode / Live
      Photos / filters / macro off, location on, airplane mode off
- [ ] Gray card, microfiber cloth, ruler packed
- [ ] Today's route from the shot list on the coverage map

## At each building

- [ ] Wipe the lens
- [ ] Gray card first frame (and again if the light changes)
- [ ] Lock exposure and focus on the wall
- [ ] Pass 1 straight on, then passes 2 and 3 angled
- [ ] Each pass at chest height and overhead
- [ ] One or two steps between shots; never zoom
- [ ] Corners: 5 to 8 shots in a slow arc
- [ ] Some ground in most shots; a line of shots to the next building
- [ ] Hero building: close-ups of doors, windows, trim, then link shots
- [ ] Swatches of any new material (with card and ruler)
- [ ] No faces filling the frame, nothing into windows, sun behind me
- [ ] Zoom in on 3 random shots: sharp and not too dark or bright
- [ ] Note: building, sides done, time

## Before going home

- [ ] Any reshoots done now (blurry, dark, missed side)
- [ ] Notes list every building and side covered
- [ ] Nothing deleted from the phone

## At the PC

- [ ] Copy originals by cable to `raw/capture/<YYYY-MM-DD>/<device>/`
- [ ] Not via messaging apps, email or "optimized" cloud sync
- [ ] Check file count and sizes match the phone (RAW files present)
- [ ] Run `python Tools/VanderbiltCampus/pipeline/intake.py <folder>`
- [ ] Read the report; add reshoots to the next trip
- [ ] Copy the day's folder to the backup drive
- [ ] Only then free space on the phone
