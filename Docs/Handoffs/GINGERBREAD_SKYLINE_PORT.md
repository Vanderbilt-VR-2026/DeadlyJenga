# Gingerbread Kingdom Skyline port

The playable Gingerbread Kingdom uses the historic bridge, palace and valley routes. This slice ports Big Ben, Peppermint Stack, Evergreen Court and Lantern Lofts from the Blender Skyline model into that playable layout. The three towers occupy former cottage parcels and Big Ben uses the middle parcel between the main routes. The three residential shells keep their Blender walls, floor openings and stairs, fitted to the Unity plots in plan. Decorative details are grouped into each shell or removable roof. The roofs are separate physics bodies with the existing gingerbread grab behavior. Clock Court uses fixed corner piers and an overhead collider with clear ground routes on both axes.

Source model: Gingerbread Kingdom - Skyline.blend, Blender 5.3.0. Run the exporter in `Docs/Tools/export_gingerbread_skyline.py` against that file with `-- <Blender review folder> <output .bytes>`. The review folder contains `gingerbread-skyline-layout.json`. The exporter strips bevel modifiers, maps the materials to the existing Unity candy palette and serializes triangle groups and independent structural boxes. `GingerbreadSkyline.bytes` contains only the resulting map data. The editable Blender source stays in the art workboard.

The expanded Blender landscape and streets, new rear Holly Court, five neighboring venues, and the rest of the handmade cottage overhaul are outside this structural slice. The checked desktop fixture uses the production Game scene and Gingerbread Kingdom catalog selection. Multiplayer and headset play are pending.
